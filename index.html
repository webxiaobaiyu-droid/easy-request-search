Features

为「找请求」而生的一切能力

从单条请求定位到成批核对，从复现到留档，一个面板全部覆盖。

参数级精确筛选

按 URL、方法、类型、状态、MIME、参数名 / 参数值、请求头、响应内容任意组合筛选，支持正则与存在性判断。

批量搜索 · 每词一色

粘贴一批 trace-id / 订单号，命中任意一个即显示；行首色条 + 关键词标签 + 命中统计图例，未命中的置灰一目了然。

响应内容搜索

「这段 JSON 是哪个请求返回的？」直接搜响应正文，base64 响应自动解码后参与匹配。

瀑布图 · 失败可见

按时间对齐的瀑布条形图定位排队与瓶颈；net::ERR 失败、取消请求有独立分组与红色标识、详情显示失败原因。

筛选预设 · 断电续跑

高级条件可保存为命名预设随时套用；当前筛选自动持久化，重开面板接着用。

一键复制 cURL / fetch / axios

任意请求三选一复制为可运行代码，自动剔除浏览器专属头，联调复现零成本。

HAR 导出 · 自动脱敏

导出通用 HAR 格式，Authorization / Cookie 等敏感头自动打码，可安全分享或导入 Charles / Fiddler。

万级请求不卡顿

列表虚拟滚动 + 5000 条环形缓冲，压测页面上千请求依旧丝滑；键盘 / ↑↓ Esc 全键盘操作。

明暗主题 · 中英双语

跟随系统深浅色并可手动固定；界面一键切换中文 / English，时间格式随语言。

Guide

三步开始使用

克隆、构建、加载，一分钟接入你现有的开发流程。

构建扩展

需要 Node 18+ 与 pnpm：

git clone https://github.com/webxiaobaiyu-droid/easy-request-search.git
cd easy-request-search
pnpm install && pnpm build

加载到 Chrome

打开扩展管理页，开启开发者模式，加载 dist 目录：

chrome://extensions → 开发者模式 → 加载已解压的扩展程序

打开面板

在任意页面按 F12，顶部找到 EasyRequestSearch 面板（未连桥时展示预览数据，可直接体验全部功能）。

F12 → 顶部 Tab「EasyRequestSearch」
