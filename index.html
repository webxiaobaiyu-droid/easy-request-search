01

为「找请求」而生

filter · search · copy
Signature · 批量搜索

多关键词批量搜索，每个词一种颜色

从日志里复制 50 个 trace-id 粘进来，命中任意一个即显示：行首色条、名称后的关键词标签、顶部命中统计图例，未命中的关键词直接置灰。

POSTsearchtenantId=3107
GETitemsWH-03
GETorderstenantId=3107+1
Precision · 参数级筛选

搜参数，而不是搜 URL

按参数名 / 路径、参数值、请求体、请求头、状态码、MIME 精确过滤；支持正则、存在性判断、AND / OR 条件组合，高级条件可存为命名预设。

Deep · 响应搜索

「这段 JSON 是谁返回的？」

直接搜响应正文，base64 自动解码参与匹配，列表内即时过滤。

Timing · 瀑布图

时间对齐的瀑布条

排队还是慢接口一眼可辨；net::ERR / 取消有独立「失败」分组与红色原因。

Privacy · 脱敏导出

HAR 导出自动打码

Authorization、Cookie 等敏感头替换为 [REDACTED]，可安全分享或导入 Charles。

02

三步上手

node 18+ · pnpm
STEP / 01

构建扩展

克隆仓库并构建产物：

# 克隆并安装依赖
git clone https://github.com/webxiaobaiyu-droid/easy-request-search.git
cd easy-request-search
pnpm install && pnpm build
STEP / 02

加载到 Chrome

扩展管理页开启开发者模式，加载 dist 目录：

chrome://extensions
→ 开发者模式 ON
→ 加载已解压的扩展程序 → dist
STEP / 03

打开面板

任意页面 F12，顶部选择面板；未连接时展示预览数据，可直接体验全部功能。

F12 → EasyRequestSearch
